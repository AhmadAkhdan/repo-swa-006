Praktikum Azure Static Web Apps

Selamat! Halaman web statis ini telah berhasil dikembangkan dan siap untuk di-deploy menggunakan layanan komputasi awan Microsoft Azure.

🚀 Azure Static Web Apps 📦 GitHub Actions (CI/CD) 🌐 HTML5 & CSS3

1. Integrasi GitHub

Deployment otomatis menggunakan GitHub Actions. Setiap kali Anda melakukan push atau perubahan kode ke repositori, web akan diperbarui secara otomatis.

2. Hosting Global yang Cepat

Konten statis Anda akan didistribusikan secara global. Hal ini memastikan halaman web dimuat dengan sangat cepat di mana pun pengguna berada.

3. Keamanan Bawaan

Mendapatkan dukungan sertifikat SSL/TLS gratis yang diperbarui secara otomatis, memastikan koneksi dari browser pengunjung selalu aman (HTTPS).
